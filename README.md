# Android Layout Editor

Android XML 布局可视化编辑器 — 拖拽设计、实时预览、代码同步,零依赖纯前端运行。

## 在线使用

**[点击打开编辑器](https://monetcarlos2026.github.io/android-layout-editor/)**

## 功能特性

- 🎨 **可视化拖拽设计** - 24+ Android 组件支持拖拽放置
- 📝 **XML 语法高亮编辑** - 内置代码编辑器,设计/代码实时双向同步
- 📦 **零依赖纯前端** - 无需后端,打开浏览器即可使用

## 部署

本站点使用 GitHub Pages 部署,直接从 `main` 分支根目录提供静态文件。
推送代码到 `main` 即自动重新部署。部署细节见 [DEPLOY.md](DEPLOY.md)。
