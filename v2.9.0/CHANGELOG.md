# LayoutEditor 修改摘要

## v2.9.0 (2026-06-04)
- **新增**: VS Code 插件版本
  - 完整编辑器功能集成到 VS Code
  - 支持 Custom Editor API，双击 XML 文件即可打开可视化编辑器
  - 支持右键菜单"Open in Layout Editor"
  - 支持侧边栏面板模式
  - 插件与 Webview 双向通信（保存、导出、打开文件）
  - 适配 VS Code 主题变量（自动跟随 VS Code 主题）
  - 新增命令：新建 Android 布局文件
- **文件结构**:
  - `package.json` - 插件配置
  - `extension.js` - 插件主入口
  - `media/style.css` - 适配 VS Code 的样式
  - `media/app.js` - 适配 VS Code 的编辑器逻辑

## v2.8.6 (2026-05-18)
- **修复**: 优化标尺显示逻辑
- **改进**: 浮动工具栏交互体验

## v2.8.3 (2026-05-18)
- **双全屏模式**：标题栏全屏按钮改为浏览器全屏，浮动工具条全屏按钮改为仅显示设计窗
- **网格数值**：Canvas 绘制网格数字标识，随缩放动态调整，显示实际像素值
- **浮动工具条**：fixed 定位，不随画布滚动
- **手机边框**：4px 边框，16px 圆角，内容区独立滚动

## v2.8.0 (2026-05-17)
- **代码重构**：DOM查询引入 $/$$ 缓存函数
- **代码重构**：renderComponentContent 拆分为24个独立渲染器
- **移除JSZip**：删除未使用的外部CDN依赖，项目零外部依赖
- **新增功能**：代码编辑器XML语法高亮 + 行号
- **新增功能**：状态栏增强（缩放比例、选中组件类型、视图模式）
- **安全增强**：清空画布和键盘删除添加确认对话框

## v2.7.5 (2026-05-17)
- **新增**：代码编辑器XML语法高亮、行号显示、滚动同步
- **新增**：状态栏显示缩放比例、选中组件类型、视图模式

## v2.7.2 (2026-05-17)
- **新增**：设计画布四边标尺（水平+垂直）
