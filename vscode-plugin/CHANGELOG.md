# Changelog

## [2.13.0] - 2026-06-04
### Added
- XML Formatting & Refactoring (Shift+Alt+F format, extract to @string/@dimen, wrap/unwrap layout)
- Performance Analysis Panel (layout depth, view count, measure estimate, overdraw detection, health score)
- Resource Management Enhancement (@drawable/@layout/@string/@dimen autocomplete, hover preview)
- Layout health score, statistics panel, overdraw heatmap overlay

## [2.12.0] - 2026-06-04
### Added
- Lint validation (9 rules: nesting, root layout, weight abuse, view count, hardcoded strings/dimensions, deprecated attrs, RTL, ScrollView+RecyclerView)
- Multi-file navigation (DefinitionProvider, DocumentLinkProvider, CodeLensProvider)
- Material 3 theme enhancement (seed color dynamic palette generation)
- Responsive multi-screen preview (2x2 device grid)

## [2.11.0] - 2026-06-04
### Added
- Code snippets & templates (8 common layout templates)
- Export to image (SVG foreignObject + Canvas)
- Accessibility checker (contentDescription, touch target, hint/labelFor, liveRegion)

## [2.10.0] - 2026-06-04
### Added
- Custom Editor API (WorkspaceEdit native undo/redo)
- XML validation & attribute autocomplete
- Resource drag-drop (image/layout files)
- Layout bounds visualization, Layout Inspector

## [2.9.0] - 2026-06-04
### Added
- Initial VS Code plugin release
- Custom Editor API support
- Context menu & command palette integration
- VS Code theme auto-follow
